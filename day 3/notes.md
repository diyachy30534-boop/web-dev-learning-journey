# Day 3 — HTML Text and Formatting

- `<h1>`–`<h6>` — headings, from highest to lowest level.
- `<p>` — paragraph.
- `<strong>` — important text, usually bold.
- `<em>` — emphasized text, usually italic.
- `<mark>` — highlighted text.
- `<small>` — smaller side text.

## Remember
- Use headings to organize content logically.
- Use paragraphs for normal text.
- Most elements have opening and closing tags.
- Formatting elements provide meaning, not just appearance.
- Save your HTML file and test it in a browser.

## Workflow
Learn → Write → Test → Debug → Review → Commit to GitHub.
