# Day 9 — CSS Selectors and Specificity

## Selectors
- Element: p
- Class: .highlight
- ID: #main-title
- Group: h1, h2, p

## Specificity
- ID selectors outrank class selectors.
- Class selectors outrank element selectors.
- If specificity is equal, the later applicable rule generally wins.

## Remember
- HTML class="card" matches CSS .card.
- HTML id="header" matches CSS #header.
- Use classes for reusable styling.
- Keep IDs unique within the page.
